# 📊 Dashboard de Vendas - Xbox Game Pass

## 📌 Descrição
Este projeto tem como objetivo ensinar a criar um **dashboard de vendas no Excel**, com foco na **organização e visualização de dados**.  
A proposta é transformar dados brutos em informações visuais claras e úteis, permitindo uma análise eficaz do desempenho de vendas e apoiando a **tomada de decisões baseada em dados**.

## 🎯 Entendendo o Desafio
O desafio consiste em:
- Utilizar uma base de dados de assinaturas do **Xbox Game Pass**.  
- Criar um **dashboard interativo** que apresente métricas relevantes de vendas e assinaturas.  
- Demonstrar como dados podem ser estruturados e analisados para gerar insights de negócio.

## 📂 Estrutura do Repositório
- `Dashboard_Vendas_Xbox` → Arquivo com **base de dados** (informações de assinantes, planos, valores e benefícios extras) e **dashboard concluído**, contendo gráficos e análises.  
- `README.md` → Documento explicativo do projeto, dados utilizados e instruções de reprodução.  

## 📊 Dados Utilizados
A base de dados contém informações como:
- **ID do Assinante**  
- **Nome**  
- **Plano contratado** (Core, Standard, Ultimate)  
- **Data de início da assinatura**  
- **Preço da assinatura**  
- **Tipo de renovação** (Mensal, Trimestral, Anual)  
- **Benefícios adicionais** (EA Play Season Pass, Minecraft Season Pass, cupons)  
- **Valor total agregado da assinatura**

## 📈 Principais Análises do Dashboard
O dashboard final apresenta:
- **Faturamento total de planos anuais**.  
- **Faturamento anual separado por auto-renovação (sim/não)**.  
- **Total de vendas do EA Play Season Pass**.  
- **Total de vendas do Minecraft Season Pass**.  

Essas análises permitem identificar:
- A contribuição de cada tipo de plano para o faturamento.  
- O impacto da auto-renovação nas receitas.  
- A relevância dos benefícios extras (EA Play e Minecraft).  

## 🚀 Como Reproduzir
1. Baixe os arquivos `base.xlsx` e `dashboard_xbox_finalizado.xlsx`.  
2. Abra o Excel (ou outro software compatível).  
3. Explore a aba de **Dashboard** para visualizar os gráficos e métricas.  
4. Caso queira refazer o processo:
   - Utilize a base de dados (`base.xlsx`).  
   - Crie tabelas dinâmicas e gráficos.  
   - Estruture o dashboard conforme o modelo finalizado.  

## 🛠️ Ferramentas Utilizadas
- **Microsoft Excel** → Para manipulação de dados e criação do dashboard.  
- **Tabelas Dinâmicas** → Para sumarização dos dados.  
- **Gráficos** → Para visualização clara das métricas.  

## 📌 Conclusão
Este projeto demonstra como dados brutos podem ser transformados em **informações estratégicas** por meio de dashboards.  
O resultado é uma ferramenta visual que facilita a análise de vendas e apoia decisões de negócio.
